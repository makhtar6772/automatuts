Automate LinkedIn Posts with n8n and AI: Step-by-Step Workflow

Published October 27, 2026 · 9 min read

Writing a good LinkedIn post takes time, and it is hard to stay consistent. This guide shows how to build an n8n workflow that reads a blog article, writes a LinkedIn post about it in your voice, creates a matching image and publishes it once you approve.

The AI does the drafting. You stay in control, because nothing goes live until you say so.

How the system works

The setup is split into two separate workflows.

  • Flow 1 (create): takes a blog URL, summarizes it, writes the post, generates an image and saves everything to Google Sheets.
  • Flow 2 (publish): reads the sheet and posts to LinkedIn only the rows you have confirmed.

The Google Sheet sits in the middle as your review step. You can read and edit each post before it goes out.

What you need

  • An n8n account
  • A Firecrawl account (reads web pages)
  • An OpenAI API key (summary and image generation)
  • An Anthropic API key (writes the post)
  • A Perplexity API key (optional web search for the first agent)
  • A Google account for Google Sheets and Google Drive
  • A LinkedIn API access token

Flow 1, Step 1: Add a trigger

The creator in the video uses a form as the trigger, but you can use anything: Telegram, Slack or any other trigger node.

The input is the link to a blog article. This is the information the AI will turn into a post. In the demo it was a blog about OpenAI's Agent Builder.

One tip for testing: if you pinned test data on the trigger, unpin it before running the workflow with a new URL. Otherwise n8n keeps using the old data.

Flow 1, Step 2: Read the blog with Firecrawl

Add a Firecrawl node. It visits the blog page and returns all of its content in Markdown format, which is clean text that AI models handle well.

Flow 1, Step 3: Summarize with the first AI agent

Add an AI Agent node. It receives the Markdown of the blog as the topic and has one tool connected: Perplexity, which lets it search the internet if it needs more information.

The prompt gives the agent two steps:

  1. If you need more information, use the Perplexity tool.
  2. Summarize the result, and create an image prompt that matches the subject.

The outputs are a summary and an image prompt. You will use both in the next steps.

Why use two different models?

This agent only summarizes, so the creator picked the cheapest option, OpenAI GPT-5 nano. Writing the final post is a different job, so it goes to a second model. Splitting the work keeps costs low and quality high. Model names change often, so check what is available when you build this.

Flow 1, Step 4: Write the post with the second AI agent

The second AI Agent node uses Anthropic Claude Sonnet 4.5, which the creator finds better at generating text and posts.

This prompt is the most important part of the whole workflow. It is where you make the posts sound like you. Include:

  • Your background: your experience and what you have worked on
  • Your target audience: your ideal customer profile (ICP), such as manufacturing executives
  • The topic: the summary from the first agent
  • Style rules: how the post should sound and what it should achieve

Ask the agent to return structured JSON that contains the final post text, so the next nodes can pick it up easily. A good tip is to make the prompt use variables, so you can swap in a different experience or audience without rewriting everything.

The example post in the video follows a clear pattern: a hook that names a pain point, a short explanation of the gap, and a closing question that starts a discussion with readers.

Flow 1, Step 5: Generate a branded image

Next, create an image with OpenAI image generation (the gpt-image-1 model). Feed it the image prompt from the first agent.

Here is the trick: also give it a reference image that represents your brand. The model uses it as a base and produces an image in a similar style. Without a reference, you tend to get a plain, obviously AI-looking picture.

The colors may still differ a little from your reference, but the overall look stays close to your brand.

Flow 1, Step 6: Save the image to Google Drive

Upload the generated image to Google Drive. Before that, add a Code node with a few lines of JavaScript that create a random ID for the file name. This way, each new image gets its own name and the previous one is never overwritten.

Flow 1, Step 7: Save everything to Google Sheets

Add a Google Sheets node and choose Append row. Your sheet needs five columns:

  • Post text: the post written by the AI
  • Image ID: the Google Drive ID of the image (needed later to download it again)
  • Image URL: a link to preview the image
  • Published: set to no
  • Confirmation: set to no, because you have not approved it yet

Run the workflow and a new row appears in your sheet.

Review and approve your post

Open the sheet and read the post. You can edit the text however you like. Check that nothing in it goes against your brand or your message.

When you are happy, change the Confirmation column to yes. That is your approval.

Flow 2: Publish to LinkedIn

The second workflow takes approved rows and posts them. Here is how it is built.

Step 1: Get the rows

Use a Google Sheets node with Get rows to read all rows from your sheet.

Step 2: Filter with an IF node

Add an IF node that checks two columns. A row goes to the true branch only when Confirmation is yes and Published is no.

Any other row goes to the false branch and nothing is posted. This keeps unapproved and already-published posts safe.

Step 3: Publish with the LinkedIn API

The creator notes that the built-in LinkedIn node in n8n had a bug and could only post to an organization page. So the workflow uses the LinkedIn API directly, with an access token for your own account. How to get that token was covered in his previous video.

The LinkedIn-related nodes run in this order:

  1. Get user info: returns your LinkedIn ID
  2. Initialize upload: prepares LinkedIn to receive an image
  3. Download file: gets the image back from Google Drive using the image ID saved in the sheet
  4. Upload image: sends the image to LinkedIn
  5. Create post: publishes the post text with the image

Step 4: Mark the row as published

The last node updates the row and sets Published to yes. This stops the same post from being published twice.

Quick summary

  • Flow 1 reads a blog with Firecrawl, summarizes it, writes a post with a second AI model and creates a branded image.
  • Everything is saved to Google Sheets and Google Drive so you can review it.
  • You approve a post by setting Confirmation to yes.
  • Flow 2 checks approved rows and publishes them with the LinkedIn API, then marks them as published.

Always read each post before approving it. The AI gives you a strong first draft, but the final say should be yours.
