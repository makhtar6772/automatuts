Auto-Post Videos to Every Social Platform with n8n and AI Captions

Published October 28, 2026 · 10 min read

Posting the same video to Instagram, YouTube, TikTok, Facebook and X by hand takes a lot of time. Every platform also likes a different style of caption.

In this guide you will build an n8n workflow that picks your next unpublished video from a Google Sheet, writes a custom caption for each platform with AI, and posts everywhere through a single API. It needs no coding, only drag and drop.

How the workflow works

  1. A schedule trigger starts the workflow (for example, once a day).
  2. It reads the next unpublished video from a Google Sheet.
  3. An AI captions agent writes a caption for every platform.
  4. The video is uploaded to a publishing service, then posted to each platform.
  5. The sheet is updated so that video is marked as posted.

The next time the workflow runs, it picks the next row that has not been posted yet.

What you need

  • An n8n account (a free trial is available)
  • A Google account for Google Sheets
  • An OpenAI API key, with a few dollars of credit added
  • A Blotato account to publish to social platforms with one API
  • Your social accounts, such as Instagram and YouTube

The creator uses Blotato instead of connecting each platform's own API. It saves a lot of setup steps and works the same way for every platform.

Step 1: Prepare your Google Sheet

The creator shares a Google Sheet template in the video description. Open it and click File, then Make a copy, so the sheet lives in your own account.

The sheet has a tab called Topics. Each row holds a video you want to publish, with details such as the topic, the video URL, a status and a posted flag.

Step 2: Create the workflow and add a schedule trigger

  1. Sign up for n8n and open your dashboard.
  2. Click Create Workflow.
  3. Add a trigger and choose On schedule.
  4. Set Trigger Interval to Days and Days Between Triggers to 1.

The workflow now runs once a day. You can pick another schedule if you like, such as every hour.

Step 3: Get the next video from Google Sheets

Click the plus icon, search for Google Sheets and choose the Get Row(s) action.

Connect your Google account

  1. Click Create new credential.
  2. Choose Sign in with Google and select your account.
  3. When you see "account connected", you are done.

Choose the sheet and filters

  • Document: select By URL and paste the URL of your copied sheet
  • Sheet: Topics
  • Filter 1: column status equals finished
  • Filter 2: column posted equals false

Then click Add option and choose Return only first matching row. This makes sure only one video is published at a time.

Click Execute step to test it. You should see the next row that is finished but not yet posted. Rename the node to Get content.

Step 4: Write platform captions with OpenAI

Add an OpenAI node and choose the Message a Model action.

Add your API key

  1. Click Create new credential.
  2. Go to platform.openai.com, sign in, open Settings and then API keys.
  3. Create a new secret key, give it a name, select a project and copy the key.
  4. Paste it into n8n and save. You should see that the connection test succeeded.

Also open Billing in OpenAI and add 5 or 10 dollars of credit. Without credit, the API will not work.

Add the prompt

Pick an OpenAI chat model, then click into the prompt field and switch it to Expression. Paste the caption instructions from the creator's template document.

The prompt begins with a line like "You are an expert social media copywriter. Write a high-performing caption for the topic." The topic is filled in automatically from your Google Sheet row.

The instructions also include platform rules, such as:

  • The maximum number of characters for each platform
  • Whether to use line breaks or emojis
  • Up to ten hashtags at the end
  • Placing the top keywords in the first 30 characters

If you do not like a rule, delete it or write your own. The end of the prompt tells the AI how to format its answer so the next nodes can use it.

Scroll down and turn on Output Content as JSON. Click Execute step and open the Schema view to see one caption per platform. Rename the node to Captions agent.

Step 5: Connect Blotato

Blotato is the service that publishes to your social platforms. Sign up for an account, then open Settings.

Connect each platform from there. For X, for example, click the login option and follow the steps. Repeat for every platform you want to post to.

Store your API key and account IDs

  1. Add an Edit Fields node and set the mode to JSON.
  2. Paste the account IDs snippet from the template document.
  3. In Blotato settings, click Copy API key and paste it into the snippet.
  4. Copy the account ID for each connected platform from Blotato and paste it in as well.
  5. Click Execute step and rename the node to Account IDs.

Now you can use these values anywhere in the workflow without typing them again.

Step 6: Upload the video to Blotato

The service needs the video on its own servers before posting. Here is how:

  1. Add an HTTP Request node and click Import cURL.
  2. Paste the upload video snippet from the template document and click Import.
  3. For the API key value, select Expression, delete the existing text and drag the API key from the Account IDs node.
  4. For the URL value, select Expression and drag in the video URL from the Get content node.
  5. Click Execute step.

The result is a URL of the same video, now stored on Blotato. Rename the node, go back to the canvas and save.

Step 7: Post to Instagram

  1. Add another HTTP Request node and use Import cURL with the post to Instagram snippet.
  2. Set the API key as an expression, dragged from the Account IDs node.
  3. Open the JSON body and click Expression.
  4. Replace the sample account with your Instagram account ID.
  5. Replace the sample caption with the Instagram Reels caption from the Captions agent.
  6. Replace the media URL with the URL returned by the upload step.

This part is a little tricky. The caption text is not valid JSON as it is, because line breaks and quotes can break it. The creator solves this with a short snippet from the template document. Paste it after the caption value so the text is cleaned up.

Click Execute step. A green checkmark means the post was sent. Rename the node.

Step 8: Post to YouTube and other platforms

Every other platform works the same way. For YouTube:

  1. Add an HTTP Request node and import the post to YouTube snippet.
  2. Set the API key as an expression from the Account IDs node.
  3. Replace the account with your YouTube account ID.
  4. Use the YouTube Shorts caption from the Captions agent for the caption fields.
  5. Use the upload URL as the media URL.

Execute the step, check for the green checkmark and rename the node. Repeat for TikTok, Facebook, X and any other platform you connected.

Step 9: Merge the branches

Add a Merge node and set the mode to Choose Branch. Set the number of inputs to match your platforms. In the demo there are two, and with all nine platforms you would set it to nine.

Connect every posting node to the Merge node. The workflow only moves on once all posts have finished.

Step 10: Mark the video as posted

Add a Google Sheets node and choose Update Row in Sheet.

  • Document: By URL, using the same sheet URL
  • Sheet: Topics
  • Column to match: topic
  • Value to match: drag the topic from the Get content node
  • Posted: set to true

You do not need to change the status or the video column. Execute the step and check your sheet. The row should now show as posted. Go back to the canvas and click Save.

A faster way: import the template

You can skip most of the building by importing the creator's ready-made workflow.

  1. In n8n, click Create Workflow.
  2. Click the three dots menu and choose Import from file.
  3. Select the template file you downloaded from the video description or community.
  4. Update the Google Sheets nodes with your copied sheet and credentials.
  5. Replace the API key and account IDs with your own.

Bonus: use it as a sub-workflow

You can also import the auto-publish sub-workflow from the same place. Import it, rename it (for example, Auto Upload Sub-workflow) and save.

In any other workflow, add an Execute Sub-workflow node and select it. You only need to provide the topic and the video URL, and the rest runs as shown above. This is handy if you already make videos with another automation.

Quick summary

  • A schedule trigger reads the next unposted video from Google Sheets.
  • OpenAI writes a caption tuned for each platform.
  • Blotato uploads the video and posts it to every connected platform.
  • A Merge node waits for all posts, then Google Sheets marks the row as posted.
